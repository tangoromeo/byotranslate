# BYO Translate — Support

**English** · [Русский](#поддержка)

## Getting started

1. Get an API key from a provider: OpenRouter (one key for many models), OpenAI, Anthropic, Google Gemini, or any OpenAI-compatible server.
2. Open the app → **Models** → **Add connection**, choose the provider, paste the key. The app suggests models; you can change them.
3. **Translate selected text:** Settings → Apps → Default Apps → Translation → BYO Translate. Then select text anywhere and tap "Translate".
4. **Translate any screen:** in the app, tap **Add the "Translate Screen" shortcut**, then assign it to the Action button, AssistiveTouch (Settings → Accessibility → Touch → AssistiveTouch → Single-Tap) or Back Tap.

## Common questions

- **"No API key set" / "Key rejected"** — check the key in Models → your connection → Check connection.
- **Part of the screen is not translated** — some stylized fonts are not detected by the on-device text detector; use the "Text" mode for the whole screenshot.
- **Translation quality** — try a stronger model in the "Strong model" slot and use "More precise".
- **Costs** — you pay your provider directly; the app shows a monthly usage counter in "Debug and usage".

## Поддержка

**Как начать**

1. Получите API-ключ у провайдера: OpenRouter (один ключ — много моделей), OpenAI, Anthropic, Google Gemini или любой OpenAI-совместимый сервер.
2. Откройте приложение → **Модели** → **Добавить подключение**, выберите провайдера, вставьте ключ. Приложение предложит модели, их можно заменить.
3. **Перевод выделенного текста:** Настройки → Приложения → Приложения по умолчанию → Перевод → BYO Translate. Затем выделите текст где угодно и нажмите «Перевести».
4. **Перевод любого экрана:** в приложении нажмите **«Добавить команду «Перевести экран»»** и повесьте её на кнопку «Действие», AssistiveTouch (Настройки → Универсальный доступ → Касание → AssistiveTouch → Одно касание) или касание задней панели.

**Частые вопросы**

- **«Не задан API-ключ» / «Ключ отклонён»** — проверьте ключ: Модели → ваше подключение → «Проверить подключение».
- **Часть экрана не перевелась** — некоторые стилизованные шрифты не находит детектор текста на устройстве; используйте режим «Текст» для всего снимка.
- **Качество перевода** — поставьте более сильную модель в слот «Сильная модель» и нажимайте «Точнее».
- **Расходы** — вы платите провайдеру напрямую; счётчик за месяц — в «Отладка и расход».
