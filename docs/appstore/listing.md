## English (primary)

**Name:** BYO Translate

**Subtitle:** Translate with your own AI key

**Promotional text:**
Translate any screen in one tap: the translation appears right over the app you're in. Works with your own API key — no account, no ads, no tracking.

**Keywords:**
translator,translate,screenshot,screen,hebrew,russian,menu,llm,api key,ocr,dictionary,language,ai

**Description:**
BYO Translate translates text and screenshots with the AI model you choose, using your own API key. No accounts, no ads, no analytics, no middleman server: your text goes straight from your phone to the provider you set up.

TRANSLATE ANY SCREEN IN ONE TAP
Add the "Translate Screen" shortcut and assign it to the Action button, an on-screen AssistiveTouch button or Back Tap. One press translates the whole screen and shows the result right over the app you're in — labels in place of the original text. Close it and you're exactly where you were.

TRANSLATE SELECTED TEXT ANYWHERE
Set BYO Translate as the system translation app and use "Translate" on selected text in Safari, Mail, Messages and every other app.

SEE WHAT YOU NEED
• Whole screen: translated labels over the original, in context of the entire screen.
• Fragments: tap any block of text to translate just that.
• Text: a plain translation of the whole screenshot.
• Pinch to zoom; right-to-left languages are laid out correctly.

BETTER TRANSLATIONS
• Two model slots: a fast everyday model and a stronger one behind "More precise".
• "Explain" adds notes on idioms, ambiguity and tone.
• Dictionary mode for single words, and a glossary for terms that must always be translated the same way.
• Model lists sorted by a built-in rating (balanced or quality-focused), with suggested defaults.

YOUR KEY, YOUR PROVIDER
Works with OpenRouter, OpenAI, Anthropic, Google Gemini and any OpenAI-compatible server (for example Ollama or LM Studio). You need an API key from one of them; you pay the provider directly for what you use.

PRIVATE BY DESIGN
• API keys are stored in the iOS Keychain.
• Text and images are sent only to the endpoint you configured. There is no server of ours and no telemetry.
• Screenshots are processed in memory and not saved.
• An optional, encrypted 24-hour cache makes repeated screens instant and stays on your device.

**What's New (1.0):** First release.

**Название:** BYO Translate

Переводите любой экран одним нажатием: перевод появляется прямо поверх приложения. Работает на вашем API-ключе — без аккаунта, рекламы и слежки.

**Описание:**
BYO Translate переводит текст и скриншоты выбранной вами нейросетью по вашему собственному API-ключу. Без аккаунтов, рекламы, аналитики и промежуточного сервера: текст уходит прямо с телефона к провайдеру, которого вы настроили.

ПЕРЕВОД ЛЮБОГО ЭКРАНА ОДНИМ НАЖАТИЕМ
Добавьте команду «Перевести экран» и повесьте её на кнопку «Действие», экранную кнопку AssistiveTouch или касание задней панели. Одно нажатие переводит весь экран и показывает результат прямо поверх приложения — перевод на месте исходных надписей. Закрыли — вы там же, где были.

ПЕРЕВОД ВЫДЕЛЕННОГО ТЕКСТА ГДЕ УГОДНО
Назначьте BYO Translate системным переводчиком и пользуйтесь «Перевести» для выделенного текста в Safari, «Почте», «Сообщениях» и любых других приложениях.

РОВНО ТО, ЧТО НУЖНО
• Весь экран: перевод поверх оригинала с учётом всего экрана.
• Фрагменты: коснитесь блока текста — переведётся только он.
• Текст: обычный перевод всего снимка.
• Увеличение щипком; языки с письмом справа налево выравниваются правильно.

ЛУЧШЕ ПЕРЕВОД
• Две модели: быстрая на каждый день и более сильная за кнопкой «Точнее».
• «Пояснить» — комментарии к идиомам, неоднозначностям и тону.
• Словарный режим для отдельных слов и глоссарий для терминов, которые всегда переводятся одинаково.
• Список моделей отсортирован по встроенному рейтингу (взвешенному или по качеству), с подсказками по умолчанию.

ВАШ КЛЮЧ, ВАШ ПРОВАЙДЕР
Работает с OpenRouter, OpenAI, Anthropic, Google Gemini и любым OpenAI-совместимым сервером (например, Ollama или LM Studio). Нужен API-ключ одного из них; за использование вы платите провайдеру напрямую.

ПРИВАТНОСТЬ ПО УМОЛЧАНИЮ
• API-ключи хранятся в Keychain iOS.
• Текст и изображения отправляются только на настроенный вами адрес. Нашего сервера и телеметрии нет.
• Скриншоты обрабатываются в памяти и не сохраняются.
• Необязательный зашифрованный кэш на 24 часа ускоряет повторные экраны и хранится только на устройстве.
